# Dream Portal Automation Framework

## Technologies Used
- Java
- Selenium WebDriver
- TestNG
- Maven

## Framework Features
- Page Object Model (POM)
- Multiple Tabs Handling
- Dynamic Table Validation
- Assertions
- Screenshot Capture
- TestNG XML Execution

## Test Cases Automated

### Home Page
- Button click validation
- Multiple tabs validation

### Diary Page
- Table row count validation
- Dream type validation

### Summary Page
- Summary data validation

## How To Run
1. Right click on testng.xml
2. Run As → TestNG Suite
